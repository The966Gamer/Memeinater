MEMEINATER 6700 for Windows (same app as Android, wrapped with Electron)

Needs Node.js (nodejs.org). Do the Supabase setup in ..\README.txt first (setup.sql + paste URL in ..\www\config.js).

1. TRY_IT.bat   - opens the app in a window to test it (first run installs things, takes a minute)
2. BUILD_EXE.bat - makes dist\MEMEINATER 6700 1.0.0.exe, one file friends just double-click

Windows SmartScreen may say "unknown publisher" the first time. Click More info > Run anyway.
The .exe has the default Electron icon in Explorer (the window itself uses your icon).
